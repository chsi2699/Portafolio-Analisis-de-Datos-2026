# Portafolio — Herramientas Avanzadas de Análisis de Datos

**Universidad del Desarrollo | Ingeniería Comercial | Segundo semestre de 2026**

## Presentación

Este repositorio reúne cuatro proyectos desarrollados durante el semestre utilizando Python, R, Power BI y Tableau.

El objetivo del portafolio es demostrar la aplicación de distintas herramientas para preparar, analizar y visualizar datos económicos y comerciales, identificando tendencias, hallazgos relevantes y oportunidades para apoyar la toma de decisiones.

## Proyectos desarrollados

### 1. Python — Depósitos a plazo en Chile

Análisis de una serie económica mensual correspondiente al número de depósitos a plazo en Chile durante el período 2009–2026.

Se utilizaron Python, pandas y matplotlib para explorar los datos, construir una serie temporal e interpretar su comportamiento.

**Hallazgo destacado:** aumento pronunciado del número de depósitos durante 2022–2023, seguido de una corrección y estabilización.

[Ver proyecto Python](./01_Python_Depositos_Plazo/README.md)

### 2. R — Índice de precios de alimentos

Análisis de la evolución mensual del índice de precios de alimentos entre enero de 2010 y agosto de 2026.

Se utilizaron R, dplyr y ggplot2 para construir una serie temporal con promedio móvil, un mapa de calor y un gráfico de variación interanual.

**Hallazgo destacado:** el índice alcanzó un máximo de 160,2 puntos en marzo de 2022.

[Ver proyecto R](./02_R_Precios_Alimentos/README.md)

### 3. Power BI — Análisis comercial de Café Altamira

Construcción de un reporte comercial interactivo a partir de tablas de ventas, productos y sucursales correspondientes a 2024–2025.

Se utilizaron Power Query para la limpieza de datos, un modelo de relaciones y medidas DAX para calcular indicadores comerciales.

**Hallazgo destacado:** Mocaccino fue el producto con mayores ingresos ($4.029.300), pero registró un margen bruto de solo 6,72 %.

[Ver proyecto Power BI](./03_PowerBI_Cafe_Altamira/README.md)

### 4. Tableau — Ventas y rentabilidad de Café Altamira

Desarrollo de un dashboard interactivo utilizando una sábana de datos con 4.648 registros de ventas entre 2024 y 2025.

Se construyeron campos calculados, indicadores comerciales y gráficos comparativos con filtros interactivos.

**Hallazgo destacado:** Bebidas Calientes lideró las ventas ($8.741.730), mientras Pastelería generó la mayor utilidad bruta ($3.620.120).

[Ver proyecto Tableau](./04_Tableau_Cafe_Altamira/README.md)

## Acceso a los proyectos

Cada carpeta contiene los archivos principales del trabajo y un README con la descripción de los datos, la metodología, los resultados y las instrucciones de ejecución.

Los notebooks de Python y R pueden abrirse en Google Colab. Los archivos de Power BI y Tableau requieren sus respectivas aplicaciones.

## Reflexión final

Los cuatro proyectos permitieron aplicar distintas herramientas de análisis de datos, desde la exploración de series económicas hasta la construcción de dashboards comerciales.

Python y R facilitaron el análisis temporal, mientras Power BI y Tableau permitieron organizar información comercial y comunicar resultados mediante visualizaciones interactivas.

El principal aprendizaje fue comprender que el análisis de datos no termina con la elaboración de gráficos: su valor está en interpretar correctamente la evidencia y transformarla en información útil para tomar decisiones.
